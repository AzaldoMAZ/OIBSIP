---

## Security Analysis

### Port 135

Microsoft RPC service.

Recommendation:

Restrict access via firewall.

---

### Port 445

SMB File Sharing.

Recommendation:

Never expose directly to the Internet.

---

### Port 3306

MySQL Database.

Recommendation:

Restrict access to trusted hosts only.
